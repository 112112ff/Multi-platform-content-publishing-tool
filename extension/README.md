# ContentBridge Publisher Bridge

这是 ContentBridge 的原创浏览器扩展 Publisher Bridge，用于验证国内平台更现实的一键发布路线：

```txt
ContentBridge Web App
  -> 浏览器扩展 Bridge
  -> 使用用户自己的平台登录态打开创作页
  -> 尝试填充标题、正文、标签
  -> 用户最终确认发布
```

## 安装方式

1. 打开 Chrome / Edge 扩展管理页。
2. 开启开发者模式。
3. 点击“加载已解压的扩展程序”。
4. 选择仓库中的 `extension` 目录。
5. 回到 `http://127.0.0.1:5173/` 使用“发送到浏览器扩展”。

## 能力边界

- 扩展不会保存账号密码。
- 扩展不会绕过平台审核。
- 扩展只使用用户浏览器中已有的平台登录态。
- 扩展会打开平台创作页并尝试填充内容。
- 最终发布必须由用户在平台页面人工确认。

由于各平台页面 DOM 经常变化，自动填充采用通用输入框探测策略；如果未成功填充，扩展会在页面右下角展示草稿面板，用户可以手动复制。
