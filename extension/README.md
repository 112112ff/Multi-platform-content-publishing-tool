# ContentBridge Publisher Bridge

这是 ContentBridge 的浏览器扩展发布桥，用来实现更接近真实国内平台的一键发布路线。

国内平台很多发布 API 不稳定或需要较高权限，所以本扩展采用类似 MultiPost 的思路：用户自己先在浏览器登录平台，ContentBridge 只把生成好的草稿发送给扩展，扩展打开对应平台创作页并尝试填充标题、正文和标签。最终发布仍由用户在官方页面人工确认。

```txt
ContentBridge Web App
  -> Publisher Bridge 浏览器扩展
  -> 复用用户自己的浏览器登录态
  -> 打开单个平台创作页
  -> 尝试填充标题、正文、标签
  -> 用户在官方页面最终确认发布
```

## 安装方式

1. 打开 Chrome / Edge 扩展管理页。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择仓库中的 `extension` 目录。
5. 回到 `http://127.0.0.1:5173/`。
6. 在主界面输入需求，确认目标平台账号已登录，然后点击“一键发布到平台草稿”。

## 能力边界

- 扩展不会保存账号密码、Cookie 或 token。
- 扩展不会绕过平台审核。
- 扩展只使用用户浏览器里已有的平台登录态。
- 扩展会打开平台创作页并尝试填充草稿。
- 平台页面 DOM 经常变化，自动填充失败时会在页面右下角展示草稿面板，用户可以手动复制。
- 最终发布必须由用户在平台官方页面人工确认。

## 当前支持平台

- 小红书：创作服务平台草稿填充。
- 知乎：写作页草稿填充。
- B站：创作中心上传页草稿填充。
- 公众号：打开公众号后台并提供草稿面板。
- 微博：打开微博发布环境并提供草稿面板。
- 抖音：创作者中心上传页草稿填充。
