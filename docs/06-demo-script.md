# Demo 录制脚本

建议时长：4 到 6 分钟。

## 录制前准备

1. 运行项目：

```bash
npm install
npm run dev
```

2. 打开页面：

```txt
http://127.0.0.1:5173/
```

3. 准备一个 Webhook 接收地址。推荐使用 `https://webhook.site/` 创建临时 URL。

4. 浏览器建议缩放到 90% 或 100%，保证工作台、发布队列和记录区域能被看清。

## 讲解结构

### 1. 开场定位

建议话术：

> 我们选择的是题目二，多平台内容发布工具。ContentBridge 的目标是让创作者只输入一份内容，就能得到多个平台的差异化发布版本，并完成发布前检查、发布编排和真实投递验证。

要点：

- 说明不是简单复制粘贴工具。
- 强调解决“平台格式、风格、素材要求不同”的问题。
- 说明当前 MVP 支持 6 个内置平台和自定义平台。

### 2. 载入内容

操作：

1. 点击“载入示例内容”。
2. 展示标题、正文、标签、封面图、视频链接。
3. 勾选 6 个内置平台。

要点：

- 说明原始内容只输入一次。
- 说明素材会影响 B站、抖音等视频平台的发布体检结果。

### 3. 多平台适配

操作：

1. 在平台队列中依次点击公众号、知乎、B站、小红书、微博、抖音。
2. 展示每个平台不同的标题、正文结构、标签和策略说明。
3. 切换“编辑 / 预览”。
4. 修改一个平台标题，再点击“恢复生成”。

要点：

- 公众号偏长图文结构。
- 知乎偏观点和讨论。
- B站偏视频简介和互动。
- 小红书偏短句和标签。
- 微博偏短内容传播。
- 抖音偏短视频脚本和镜头提示。

### 4. 发布体检和发布编排

操作：

1. 展示健康分、风险提示和修改建议。
2. 展示“平台任务状态”面板。
3. 说明就绪、待补素材、阻塞、发布中、成功、草稿、失败的含义。

要点：

- 发布不是一键盲发，而是先体检。
- 每个平台可独立判断是否能发布。

### 5. Webhook 真实投递

操作：

1. 在“发布通道”选择 `Webhook 实发`。
2. 填入 webhook.site 的 URL。
3. 点击“真实投递到 Webhook”。
4. 切到 webhook.site 页面，展示收到的 POST 请求和 JSON payload。
5. 回到项目页面，展示发布记录。

要点：

- 说明这是实际 HTTP POST，不是纯模拟按钮。
- 说明官方平台直发需要 OAuth、开放接口和审核，未来可由后端 Publisher 替换 Webhook 接收端。
- 说明前端适配器、体检和发布编排不用重写。

### 6. 自定义平台扩展

操作：

1. 在“自定义平台接入中心”新增一个平台，例如：

```txt
平台名称：快手
平台定位：短视频社区
内容策略：强开场、短句、引导评论
语气：轻快、直接、有行动感
必需素材：视频
标题字数上限：24
推荐标签：短视频，经验分享，效率工具
```

2. 点击“接入自定义平台”。
3. 展示该平台出现在目标平台、预览工作台和发布任务状态中。

要点：

- 这证明“扩展更多平台”不是只写在文档里。
- 页面配置会动态生成 `PlatformAdapter`。

### 7. 架构说明

建议话术：

> 我们把平台差异封装成统一的 PlatformAdapter，每个平台只需要实现 adapt、validate、publish。主流程只关心 adapter 列表，所以新增平台不会改动核心工作台。

可展示文件：

- `src/types/platform.ts`
- `src/adapters/registry.ts`
- `src/adapters/customAdapter.ts`
- `src/services/adaptContent.ts`

### 8. 工程过程和规则合规

要点：

- 仓库在开题后创建。
- 开发过程通过多个小 PR 持续提交。
- 每个 PR 单一功能，有功能描述、实现思路、测试方式和分工说明。
- README 列明第三方依赖和原创功能边界。
- Demo 视频链接最终放入 README。
- 截止后仓库改为 Public。

### 9. 结尾

建议话术：

> 这个 MVP 已经完成从内容输入、多平台适配、发布体检、发布编排，到 Webhook 真实投递和自定义平台扩展的闭环。后续接入官方平台时，可以在后端实现带 OAuth 的 Publisher，前端工作台和适配架构可以继续复用。

## 录制检查清单

- 声音清楚。
- 页面不要遮挡关键按钮。
- 展示 Webhook 接收成功。
- 展示自定义平台新增成功。
- 展示 README 和架构文档。
- 视频上传后确认链接可播放。
- 把视频链接写回 README。
