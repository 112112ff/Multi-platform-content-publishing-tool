# ContentBridge 内容桥

面向创作者的多平台内容发布 MVP。用户只需要输入一份原始内容，系统即可自动适配公众号、知乎、B站、小红书等平台的格式与风格，支持平台预览、二次编辑、发布校验、模拟一键发布，并通过平台适配器架构扩展更多发布渠道。

## 项目目标

本项目选择第二批议题中的「题目二：多平台内容发布工具」。

我们希望做的不是简单的复制粘贴工具，而是一个能够帮助创作者理解平台差异、降低多平台发布成本的内容工作台：

- 一次输入，多平台生成。
- 不同平台展示不同的内容风格和格式。
- 发布前给出健康分、风险提示和修改建议。
- 支持模拟发布，完整展示从创作到发布的闭环。
- 架构上支持新增抖音、微博、快手等更多平台。

## 核心功能

- 内容输入：标题、正文、标签、封面图、视频链接、目标平台。
- 示例内容：一键载入 Demo 内容，便于演示和测试。
- 平台适配：为公众号、知乎、B站、小红书生成差异化版本。
- 适配说明：说明每个平台为什么这样改写。
- 发布体检：根据平台规则给出健康分、错误和建议。
- 预览编辑：用户可在发布前修改各平台版本。
- 模拟发布：展示成功、失败、草稿、模拟链接和发布时间。
- 发布记录：保留历史发布结果，形成完整演示链路。
- 扩展架构：通过 `PlatformAdapter` 新增更多平台。
